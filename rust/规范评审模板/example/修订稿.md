## 表达式与流程控制

### G.EXP.01 避免条件表达式永远为 true 或 false

**【级别】** 建议

**【描述】**

条件表达式永远为 true 或 false 通常是因为代码编写错误。

**【反例】**

```rust
let x = 2;
if (x & 1) == 2 { // 不符合：该表达式会永远是 false
    // ...
}

if (x & 3) < 4 { // 不符合：判断表达式结果永远为 true
    // ...
}

let y = 0;
if (x < y) && false { // 不符合：判断表达式结果永远为 false
    // ...
}

if x > 10 && x < 5 { // 不符合：区间矛盾，永远为 false
    // ...
}
```

**【正例】**

```rust
let x = 2;
// 符合
if x == 2 {
    // ...
}
```

**【检测】** 部分支持

- `clippy::bad_bit_mask`：位掩码与比较组合恒值（反例 1、2）。
- `clippy::overly_complex_bool_expr`：布尔表达式中可消去的项（反例 3）。
- `clippy::impossible_comparisons`：区间矛盾（反例 4）。
- `clippy::absurd_extreme_comparisons`、rustc `unused_comparisons`：与类型极值比较（如 `u32 >= 0`）。
- `clippy::eq_op`：两侧相同的比较（如 `x == x`）。
- 以上 Clippy lint 在 1.89 均属 correctness（默认 deny），rustc 的 `unused_comparisons` 默认 warn。
- 不覆盖：如 `x % 2 == 2`、`x != 1 || x != 2`。
