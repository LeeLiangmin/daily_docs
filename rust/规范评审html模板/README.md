# 规范评审对照稿 · 模板

评审会议用的对照稿，每条规范只展示四样内容：总览一行、原/现定级、原/现 lint、原文与修订稿的逐行文本对照。

| 文件 | 说明 |
| --- | --- |
| `规范评审对照稿-模板.html` | 示范成品（一条示范条款 G.EXP.01），浏览器直接打开 |
| `gen_review.py` | 生成脚本，只依赖 Python 3.11+ 标准库 |
| `example/` | 示范输入（`原文.md`、`修订稿.md`、`clauses.toml`），上面的 HTML 就是用它们生成的 |

## 使用方法：交给大模型生成

把整个 `template/` 目录和你的原文、修订稿一起交给大模型，让它参考模板和脚本生成对照稿。


提示词示例：

> 请参考 `template/` 目录，为我的规范生成一份评审对照稿：
> - `规范评审对照稿-模板.html` 是成品样例，`gen_review.py` 是生成脚本（开头注释写明了输入约定），`example/` 是示范输入。
> - 我的原文是 <文件>，修订稿是 <文件>，需要评审的条款是 <条款ID 列表>。
> - 各条款的检测能力和原/现 lint 如下：<逐条列出；或者让大模型根据修订稿中的【检测】字段整理>。
>
> 请按 `example/` 的格式整理出原文 md、修订稿 md 和 clauses.toml，然后运行 `gen_review.py` 生成 HTML。不要改写规范正文。

生成后，在浏览器中打开对照稿，逐条核对定级和 lint。这两项来自你提供的信息，脚本只检查格式，不检查内容是否正确。

## 输入约定（供核对）

- **原文 md / 修订稿 md**
  - 每条规范以 `### 条款ID 标题` 开头，分类取上方最近的 `## 分类` 标题
  - 定级取自 `**【级别】** 建议` 一行，原文与修订稿不一致时，总览中显示为「原 → 现」
  - 修订稿中的 `**【检测】**` 字段不放入对照
  - 标题使用原文中的标题
- **clauses.toml**：每条一个 `[[clause]]`，只输出写进来的条款，按书写顺序排列。字段见 `example/clauses.toml` 中的注释：
  - `id`
  - `support`：完全支持 / 部分支持 / 不支持
  - `lint_old`、`lint_new`
  - 可选 `level`：md 中没有【级别】行时（如原则类条款）需要填写
- **运行**：

  ```bash
  python gen_review.py 原文.md 修订稿.md clauses.toml -o 规范评审对照稿.html
  ```

  输入有误时，脚本会报错并指出是哪一条。

## 不用脚本时：页面布局说明

脚本跑不起来，或者条款格式与上面的约定差别太大时，可以把本节和 `规范评审对照稿-模板.html` 一起交给大模型，让它直接写出 HTML。样式可直接复制模板中的 `<style>`。

页面是单个 HTML 文件，单栏布局，从上到下依次为：

1. **标题**：「规范评审对照稿」。下面不加副标题、说明或统计数字。
2. **总览**：一张表，每条规范一行，共 4 列：
   - **条款**：条款 ID，链接到下方对应条款
   - **标题**：原标题
   - **定级**：未调整时写现定级；有调整时写「原 → 现」
   - **检测能力**：完全支持 / 部分支持 / 不支持，显示为彩色标签
3. **各条款卡片**：按总览顺序排列，每条一张卡片，卡片内从上到下依次为：
   - **头部**：一行是「条款 ID · 分类 · 检测能力标签」，下面是原标题（大字）
   - **定级**：两行，分别是「原定级　X」「现定级　Y」
   - **lint**：两行，分别是「原 lint」「现 lint」。每个 lint 名单独占一行，用等宽字体；没有 lint 时写「（无）」
   - **文本对照**：左右两栏的表格，左栏是原文，右栏是修订稿，两栏各带行号
     - 内容从条款标题行到条款末尾，全部展开，不折叠
     - 修订稿的【检测】字段不放进来
     - 两侧相同的行原样并排
     - 改过的行：左侧标红并高亮被删除的片段，右侧标绿并高亮新增的片段
     - 只有一侧有的行：另一侧留空，用斜纹底色表示
4. **不要加的内容**：侧边栏、修订理由、POC、配置、页脚，以及任何解释性文字。
