# 美观与版面合理性

密度 ≠ 拥挤。好看的高密度页 = **短标题 + 一条结论 + 对齐的块 + 一致的间距 + 克制的强调**。
本文件回答三件事：标题怎么写短、版面怎么排稳、交付前怎么自查。

## 1. 标题：短标题 + 结论副标题

每页两行文字各司其职：

| 层 | 类名 | 作用 | 长度 |
|---|---|---|---|
| 短标题 | `.title` | 告诉读者“这页讲什么”，可作为目录条目 | ≤ 18 个汉字等效（拉丁字符按 0.55 计），不含逗号，不写完整句子；talk 档 ≤ 12 |
| 结论副标题 | `.lede` | 一句话给出“所以呢”，含关键限定词和数字 | ≤ 40 字，单行 |

改写示例：

| 太长（旧） | 短标题 | 副标题 |
|---|---|---|
| rustc 把源码降级成五种表示，Rust 特有的检查都发生在前三种 | 编译流水线 | 五种中间表示，Rust 特有的检查集中在前三种 |
| no-cache 并不是不缓存，禁止存储要用 no-store | 缓存指令 | no-cache 不是“不缓存”，no-store 才是 |
| 依赖按主版本兼容范围解析，结果锁进 Cargo.lock | 依赖解析 | 按主版本兼容范围解析，结果锁进 Cargo.lock |

规则：
- 标题用名词或名词短语（“条件请求”“新鲜度判定”），不用逗号、不用“……是……”句式。
- 论点仍然要有：放在 `.lede`。整套只要坚持“每页有一句结论”，叙事就不会丢。
- 副标题不重复标题里的词，只补标题没说的内容。
- 目录页只列短标题；短标题连起来读应该像一份提纲。
- 结论条 `.callout` 与副标题不能说同一件事；副标题在上、给结论，结论条在下、给行动 / 反例 / 阈值。

## 2. 间距与对齐

- **间距只用 8 的倍数**：8 / 16 / 24 / 32 / 48。块间 24–32，块内边距 24–28，标题与内容间 24。
- **左边缘只有一条线**：标题、内容、页脚都对齐到左内边距（外壳 112px）。块内文字与块的左缘也对齐，不要每个块各缩进不同。
- **同一行的块等高**：并排块用 `.cols`（默认拉伸）而不是各自定高。
- **内容区用满，且随内容分布**：`.body{flex:1}`；块多用 `.cols` / `.grid`；块少的轻量页用 `.body.mid` 让内容整体垂直居中；结论条固定贴底（`.callout` 自带 `margin-top:auto`）。
- **不要让卡片高度大于内容**：卡片里的字占不到一半高度，就说明字太小或块太高。做法按顺序：先加 `.lg` 放大字，再用 `.fit` 让网格按内容高度，最后才是补内容。
- 页脚位置全套固定；内容不进入页脚上方的安全区（外壳下内边距 120px）。

## 3. 层级与强调

- **一页只有一个视觉焦点**：最大的元素（大数字、主图、主表）就是焦点，其他块为它服务。
- 字阶固定 `96 / 56 / 32 / 28 / 26 / 24 / 22`，靠字号分层，不靠加粗一切。
- 强调只用三种：**强调色 `.hl`**、字重、等宽（命令 / 标识符）。一个块里强调词不超过 3 个。
- 整页强调色文字占比 < 10%；整页不出现第 4 种颜色。
- 次要信息用 `--muted` 灰，不要缩小字号来表示“次要”（字号有下限）。

## 4. 块的样式

- **卡片**：一层就够。**卡片里不再套卡片**；卡片里分组用标题 + 空行，或用一条分隔线。
- **表格**：只用横线（表头强调色下划线 + 行间浅线），不画竖线、不做斑马纹；首列加粗；数字列右对齐；行高 ≥ 44px。`.tbl.fill` 让表格撑满列高。
- **代码**：深色底 `.code`，等宽，8–14 行，行长 ≤ 60 字符；用 `.k`（关键字 / 头名）、`.c`（注释）、`.e`（重点结果）三种色，最多。
- **流程**：`.flow` 节点等宽，箭头单独占列；节点写“职责 + 产物”，不要只写名称。
- **图示**：SVG 按 1:1 绘制，颜色只用主题令牌里的色。
- **结论条**：整页最多一条，贴底，一行。

## 5. 配色与主题交替

- 三个主题：`dark`（技术、章节页）/ `light`（正文、表格）/ `accent`（观点、大数字、总结）。
- 节奏：深 → 浅 → 浅 → 深 → 浅 → 强调 …；不要连续 4 页同色，`accent` 全套 ≤ 15%。
- 主题令牌已验证对比度，直接用 `var(--fg)`、`var(--muted)`、`var(--accent)`；不要在页里另写十六进制颜色。要换品牌色，只改外壳里的令牌，并重新用 `check_deck.py` 验证对比度。

## 6. 版面合理性自查（每页 10 秒）

1. 遮住文字，只看形状：有没有一个明显的焦点？左边缘是否成线？
2. 上下留白是否均衡？下方是否有整块空白，或上方内容顶到标题？
3. 并排的块是否同高、同基线、同间距？
4. 标题是否单行？副标题是否单行？
5. 有没有块里的字比块小得多（空卡片）？
6. 强调是否超过三处？颜色是否超过主题令牌？
7. 读一遍：标题 → 副标题 → 证据 → 结论条，逻辑是否顺？

自动部分：页面内置自检（按 C 或网址加 `?check`）覆盖 2、4、5 与溢出、小字；静态脚本覆盖标题长度、密度、对比度、节奏。其余靠人眼。
