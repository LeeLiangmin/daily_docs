# 输出目标与交付

先看当前环境提供了什么，再选输出形式；不要假设有某个特定工具。

## 选择顺序

1. 环境里有专用的幻灯片编辑器 / 幻灯片文件类型 → 用它（用户可以直接在里面改）。
2. 用户明确要 `.pptx` → 生成 PPTX（python-pptx 或 pptxgenjs）。
3. 用户要 PDF / 可打印 → 先做 HTML，再用无头浏览器或浏览器打印导出 PDF。
4. 只要预览 / 在线分享 → 单文件 HTML，**用 `assets/deck-shell.html` 起手**（详见 `html-viewer.md`）。

用户说“做个 PPT”但没指定文件格式时，优先第 1 条；只有明确说要 `.pptx` 文件才落到第 2 条。

## 生成 HTML 的注意点

- 直接复制 `assets/deck-shell.html`，只在 `SLIDES` 区域增删 `<section class="slide dark|light|accent">`；版面参考 `assets/layouts-gallery.html`；不要重写居中和缩放逻辑。
- 固定画布 1920×1080；`.slide` 必须 `box-sizing:border-box`（外壳已处理）。
- 字体用 `<link>` 引入，并写好回退字体栈。
- 不依赖外部脚本；键盘、点击、触摸翻页与全屏都由外壳提供。
- 交付前运行 `scripts/check_deck.py`；能开浏览器就按 C 键（或 `?check`）看页面内置自检；不需要也不要求安装 Playwright。

## 生成 PPTX 的注意点

- 版式：16:9，13.333 × 7.5 英寸；把 px 设计稿按 1px = 0.00694 英寸换算。
- 字号：px → pt 乘以 0.75（24px = 18pt）。
- 字体：用户机器不一定装了你选的字体，选 Google 字体时要在回复里提示，或改用系统字体做 PPTX 版。
- 演讲者备注写进 notes 字段。
- 表格用原生表格对象，不要用图片；图表优先用原生图表，便于用户修改。

## 交付说明（回复里写什么）

- 一两句话说明产出了什么、页数、整体风格。
- 列出用了 `[待补]` 占位的位置。
- 需要用户确认的事实（版本号、数字、出处）单独点出。
- 不要复述每一页内容，用户自己可以打开看。
