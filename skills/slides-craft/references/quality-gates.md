# 质量门禁：脚本查不到的部分

`scripts/check_deck.py` 只能量“多不多、齐不齐、单不单调”。它通过，不代表内容正确、逻辑自洽。
一份 deck 可以 0 告警，同时前后矛盾、数字无法复算。下面这些要在交付前人工过一遍。

## 门禁顺序

1. 内容门：事实、数值、术语对不对
2. 一致性门：跨页有没有互相矛盾
3. 密度门：跑脚本，处理偏稀 / 偏满 / 常量列
4. 节奏门：整套有没有起伏，版式是否单一
5. 视觉门：字号、对比度、SVG 尺度
6. 交付门：占位符、需核实事项、备注

## 1. 事实表（一致性的抓手）

写完大纲后建一张“事实表”，放在工作草稿里，交付前逐页对照：

| 项 | 内容 |
|---|---|
| 反复出现的概念 | 每个概念一句标准定义，全套统一措辞 |
| 反复出现的数值 | 数值、单位、来源或推导（例：700 ps ÷ 200 ps ＝ 3.5 倍） |
| 全套结构 | 目录声称的部分数、各部分包含哪些页 |
| 对外承诺 | 目录里“听完你能……”的每一条对应哪一页 |

## 2. 常见内容错误模式（通用）

| 模式 | 例子 | 检查办法 |
|---|---|---|
| 单位混用 | 延迟按“拍”说，加速按“时间”说，得出互相冲突的结论 | 每个量写明单位；周期数和时间分开写 |
| 例子数值没代入公式 | 给了公式和示例延迟，却说“接近 N 倍”，代入结果是另一个数 | 页面上写出：输入 → 公式 → 结果 |
| 副标题断言强于证据 | 副标题“连续两次才翻转”，实际只在强状态成立 | 副标题里的限定词（总是、只要、连续）逐个找依据 |
| 图与表不一致 | 图里两条指令作废，表里写 2–3 拍；同类条目画法不一 | 同一现象的图、表、文字，数字逐项对 |
| 排序度量不明 | “按代价排序”，但代价指硬件、性能还是编译器工作量 | 副标题写明排序度量 |
| 小结与正文矛盾 | 正文说延迟变长，小结说延迟不变 | 小结的每条回到正文，逐条对 |
| 章节结构不符 | 目录说四个部分，页眉编号到 07 | 页眉编号和目录一次生成，不手写两遍 |
| 无依据的分类断言 | “前三级与指令集相关，后两级偏微架构” | 没有出处的分类不上屏 |

## 3. 可推导性规则

- 任何比值、加速比、占比、CPI、成本、延迟，页面上要能看到输入、公式、结果。
- 表格里的数字要么来自这些计算，要么标注为“示意值”并写清参数；不允许无参数的“约 1.3”。
- 用户无法复算的数字，等于没有给。
- 易变事实（版本、默认值、发布日期、价格、命中率经验值）在备注里写来源，或明确标“需核实”，并列入交付说明。

## 4. 承诺到交付的映射

- 目录或开场里写的“听完你能……”“你将学会……”，每条必须落在具体一页，页码写进那页备注。
- 找不到对应页的承诺，要么补一页，要么删掉承诺。
- 典型缺口：承诺“能画时空图”，全套却没有一张完整的时空图。

## 5. 结论条规则

- 结论条（“所以 / 结论 / 注意”）只在能提供新信息时用：含义、反例、阈值、行动、适用条件。
- 不复述标题和副标题，不复述表格里已有的数字。
- 一套里出现在页数的 40% 以内；其余页让证据自己说话。

## 6. 假密度识别

- 常量列：整列值都相同，删掉。
- 可推导列：能由前两列直接推出的列，合并进前一列。
- 复述：小结、副标题、结论条三处说同一件事，只留一处。
- 装饰：没有对应信息的图标和色块。
- 空泛表述：“提升效率”“更加灵活”这类任何主题都能套用的话。

## 7. 节奏

- 最高密度的页不超过六成；其余是中等密度与低密度页。
- 每 4–5 页放一张锚点页：一张大图、一个大数字、一个核心示例或现场演示。
- 版式至少 3 种；表格页不连续超过 3 页。
- 同类图保持统一的尺度、配色语义和标注方式。

## 8. 用途对齐

- 交付前问一句：这份稿是“现场讲”还是“会后读”？
- 声称现场讲，但每页都在词数上限，说明是讲义密度。做“屏幕版 + 讲义版”两版：屏幕版保留论点和核心图，表格和参数放讲义。
- 经验值：现场讲每页停留 1.5–2 分钟；单页超过约 180 词，观众读屏和听讲会互相干扰。

## 9. SVG 与图

- SVG 按 1:1 绘制：viewBox 宽度等于显示宽度；固定高度的图，viewBox 高度等于显示高度。
- 图内文字有效字号 ＝ 写的字号 × 缩放，不能低于该档最小字号。
- 图要有信息：节点带职责或产物，边带数据或条件；纯方框加箭头算装饰。
- 典型的图要完整：状态机画出自环，时空图画出所有在途指令和气泡，同类条目画法一致。
