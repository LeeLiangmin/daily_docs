# 设计规则

画布以 1920×1080 为基准；用 PPT 的 13.33×7.5 英寸时，1px ≈ 0.0069 英寸（字号 24px ≈ 18pt）。
信息量与文字量的取舍见 `density.md`；本文件只管“怎么让它好看且好读”。

## 1. 先决定一个方向

为这次的主题选一个视觉方向，让它决定配色、字体和版式习惯，而不是每页凭感觉。

| 场景 | 建议方向 |
|---|---|
| 技术分享 | 深色 / 暖灰底 + 一个暖色强调 + 无衬线 + 等宽 |
| 学术 / 政策 | 浅色底 + 衬线标题 + 克制的单色强调 |
| 产品 / 路演 | 大图 + 大字 + 高饱和强调色（此类可用 talk 档） |
| 教学 | 圆润字体 + 清晰分块 + 多用图示 |

## 2. 颜色（整套只定一次）

- 1 个深色、1 个浅色、1–2 个强调色，外加一个中性灰用于次要文字。
- 深、浅两种背景交替，再留一页强调色背景做“观点页 / 小结页”。
- 白和黑向主色调偏一点：`#f5f0e8`、`#1b1815` 这类。
- 同一个强调色在深底和浅底上常需要两个明度（如 `#e0693a` 用于深底，`#b8481c` 用于浅底）。
- 对比度：正文 ≥ 4.5:1；≥ 44px 的大字 ≥ 3:1。
- 必须区分的颜色除色相外还要有明度差；避免红 / 绿单独区分。
- 颜色不单独传递含义：风险高、同比 +4% 等要有文字。

## 3. 字体与字阶

- 1–3 种字体：标题与正文可以同一种，代码用等宽。
- 字阶 5–7 级并全套复用。外壳已定：`96 / 56 / 32 / 28 / 26 / 24 / 22`。
  分工：封面 96；页标题 56；副标题 30；块标题 32；结论条 28；正文 26；说明与表格 24；页脚与标注 22。
- 强调靠字重、斜体、颜色，不靠再加字号。
- 行高：标题 1.1–1.15；正文 1.4–1.5；代码 1.5–1.6。
- **各档最小字号**：talk 24 / tech 22 / read 20。低于最小值就拆页或删次要信息，不要继续缩。

## 4. 版式与留白

- 页边距：talk 128px；tech / read 96–112px（多出来的宽度给证据）。页脚放在距底边 48–64px，一行 22–24px。
- **一页一个论点，用足够证据撑起来**：论点唯一，证据可以多（2–4 个块）。
- 标题固定在顶部同一位置；标题下方的证据区用满宽度：两栏、三栏或 6 列。
- 版面细则（间距 8 的倍数、对齐、层级、表格 / 卡片 / 代码样式、自查）见 `aesthetics.md`。
- 内容填充：talk 60–75%；tech / read 80–95%。页面下方大块空白，说明还有证据可以放。
- 相邻的块留 24–32px 间隙，块内边距 24–32px；不要用更大的边距把空间“撑”出留白感。
- 图片：照片 cover；截图 / 图表 contain 并放在对比色底上。
- 表格、代码、示意图是密度的主载体，优先于纯 bullet；并列且同属性的条目用表格，有顺序的用步骤序列。

## 5. 叙事

- **短标题写主题，副标题写结论**：标题 ≤ 18 字、无逗号；结论放 `.lede`，全套保持同一种语法（详见 `aesthetics.md` §1）。
- 避免“不是 X 而是 Y”式的戏剧化写法，直接说结论。
- 备注写 3–6 句：展开、口头解释、可能的追问；但关键结论必须上屏。

## 6. 交付前检查清单

- [ ] 每页有背景色，文字对比达标
- [ ] 字号 ≥ 该档位最小值，全套字号 ≤ 6 级，字体 ≤ 3 种
- [ ] 每页有短标题（≤ 18 字，无逗号）+ 结论副标题 + ≥ 2 个结构化证据块（tech / read 档）
- [ ] `check_deck.py --profile <档位>` 无“偏稀”“偏满”提示
- [ ] 通过删除测试（见 density.md）
- [ ] 页脚位置一致；没有内容进入底部安全区
- [ ] 没有编造的数据；占位符已在回复里列出；易变事实已标注需核实
- [ ] 每页有演讲者备注
- [ ] 事实表已对照：数值、术语、章节数、承诺都前后一致（`quality-gates.md`）
- [ ] 每个比值、CPI、占比在页面上能推导出来
- [ ] 结论条只在有新信息时出现，占比 ≤ 40%，且不复述副标题
- [ ] 页面内置自检（C 键）无问题：无溢出、标题与副标题单行、无空卡片、无小字
- [ ] 至少 3 种版式，含 1–2 张低密度锚点页
- [ ] SVG 按 1:1 绘制，图内有效字号 ≥ 该档最小值
