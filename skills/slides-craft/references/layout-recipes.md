# 版式配方（基于外壳组件类）

所有配方都用 `assets/deck-shell.html` 里的类，不写内联颜色。**完整可运行示例见 `assets/layouts-gallery.html`**（11 页，直接复制页面改内容）。
PPTX / 其他编辑器里，同样结构映射成文本框与形状：标题 56px → 40pt，副标题 30px → 22pt，正文 26px → 20pt。

## 页面骨架

```html
<section id="x" class="slide light">
  <div class="hd">
    <p class="eyebrow">02 · 章节</p>
    <h2 class="title">短标题</h2>            <!-- ≤ 18 字，无逗号 -->
    <p class="lede">一句话结论</p>           <!-- ≤ 40 字，单行 -->
  </div>
  <div class="body">                          <!-- 撑满剩余高度 -->
    <div class="cols"> … 证据块 … </div>
    <p class="callout"><b class="hl">所以：</b>…</p>   <!-- 可选，贴底 -->
  </div>
  <p class="ft"><span>演示标题</span><span class="pg"></span></p>
  <aside class="notes">备注</aside>
</section>
```

## 布局工具类

| 类 | 作用 |
|---|---|
| `.cols` + `.col`（`.w2` `.w3`） | 并排列，按比例分宽，等高 |
| `.grid.g2/.g3/.g4` | 等分网格；`style="grid-template-rows:1fr 1fr"` 做 2 行 |
| `.card`（`.lg`） | 块；`.lg` 放大字用于内容较少的卡片 |
| `.fit`（加在 `.grid` / `.cols`） | 不拉伸，按内容高度 |
| `.body.mid` | 无结论条的轻量页，内容整体垂直居中 |
| `.tbl`（`.fill`） | 横线表格；`.fill` 撑满列高 |
| `.code` | 深色代码块；`.k` 关键字 `.c` 注释 `.e` 重点 |
| `.flow` + `.node` + `.arr` | 横向流程 |
| `.step` | 步骤行：编号 · 动作 · 命令 · 预期 |
| `.kpi` | 大数字 |
| `.callout` | 结论条 |
| `.m` `.hl` | 等宽 / 强调色 |

## 配方

| 配方 | 结构 | 图库页 | 用于 |
|---|---|---|---|
| 表格 + 侧栏 + 结论条 | `.cols`：`.col.w3` 放 `.tbl.fill`，`.col.w2` 放 2 张 `.card.lg`；底部 `.callout` | table-diagram | 概念、参数、指令清单 |
| 流程 + 推导 | `.flow` 一行 N ≤ 4 个 `.node`，下方 `.cols` 放推导与概念卡 | flow | 判定顺序、流水线 |
| 带批注的代码 | `.col.w3` 放 `.code`，`.col.w2` 放 3–5 条 `.note`（编号 + 一句话） | code | 机制、API、协议 |
| 左右对比 | 两张 `.card.lg`，各含 `.tag` 标签 + `h3` + 3–4 条 `ul`；底部 `.callout` 给取舍 | compare | 方案对比、前后对照 |
| 大数字 | `.cols`：左 `.kpi` + 一行说明，右 `.col.w2` 放推导与例外两张卡；用 `accent` 主题 | bignum | 锚点页，一个关键数字 |
| 步骤 / 配置表 | 表头行 + 3–5 个 `.step`；底部 `.callout` | steps | 排障、配置、操作 |
| 卡片网格 | `.grid.g3` 两行，每格 `.card.lg`：`.tag` + `h3` + `.sub` | cards | 坑、清单、特性 |
| 目录 | `.body.mid` + `.grid.g4.fit`，每卡：编号 `.kpi`(96px) + `h3` + 一句摘要 + 页码 | agenda | 目录、锚点 |
| 总结 | `.body.mid` + `.cols.fit`，每卡对应目录里的一个问题 | summary | 收尾，与目录一一对应 |
| 封面 / 结束 | `.cover`，`.title` 96px + `.lede` | cover / end | 首尾 |

## 每种配方的填充要点

- **表格**：行 5–8，列 3–4；同属性条目才进表，整列相同的列删掉。
- **流程**：节点写“问题 / 职责 + 产物”，不要只写名称；下方补一个例子或推导。
- **代码**：批注写“为什么 / 结果”，不复述代码。
- **对比**：两侧条数相等，并且每侧末尾有“适合什么”。
- **大数字**：数字 + 输入 → 公式 → 结果；示意值要标“示意”。
- **步骤**：动作、命令、预期三列都有内容。
- **卡片网格**：每张卡里有一个具体名称或数字；六张卡不写六个抽象名词。

## 节奏与轮换

- 同一套至少 3 种配方；表格类不连续超过 3 页。
- 每 4–5 页放一张低密度锚点页：大数字、目录、总结、强调色页。
- 主题交替：`dark` / `light` / `accent`，不连续 4 页同色。

## 锚点页（低密度，调节节奏）

文字量 30–80 词，但信息不能空：
- **大数字页**：一个数字 + 一句意义 + 一行推导。
- **大图页**：一张占满宽度的核心示意图，图下一行“怎么读”。
- **反例页**：左“直觉上应该成立”，右“实际发生了什么”。
- **演示 / 练习页**：最小可运行示例 + 预期输出，或先算的题，答案放下一页。

## 图的画法（SVG）

- 按 1:1 绘制：viewBox 宽度等于显示宽度（如 1696），字号直接写最终值（≥ 该档最小值）。
- 状态机画出自环；时空图画出所有在途条目与气泡，同类条目画法一致。
- 节点里放职责或产物，边上标数据或条件；只有方框和箭头的图不算证据块。
- 颜色只用主题令牌：`fill="var(--card)" stroke="var(--line)"`，强调用 `var(--accent)`。
