HTML Slides

用一个 HTML 文件做演示

零依赖、可离线、可导出 PDF。这份示例本身就是版式说明书。

01

版式一览

每页演示一种版式，标题说明它适合放什么内容

标准页适合 3–5 条要点，标题直接写结论

  • 每页只讲一个观点，标题就是这个观点
  • 要点不超过 5 条，每条不超过两行
  • 带 class="step" 的元素按 → 逐条出现
提示框：放这一页最想让听众记住的一句话

两栏适合对比两个选项

方案 A 推荐

  • 优点一
  • 优点二
  • 代价

方案 B 备选

  • 优点一
  • 优点二
  • 代价

三栏适合并列的三个概念

简单

一个文件，浏览器直接打开，不需要安装任何软件

可离线

不依赖网络和外部资源，内网环境也能放映

可打印

按 P 打印，另存为 PDF 发给没来现场的人

03

代码与收尾

新增一页只需要复制一个 section

index.html
<!-- 标准页 -->
<section class="slide">
  <h2>标题写结论</h2>
  <div class="body">
    <ul>
      <li class="step">要点</li>
    </ul>
  </div>
  <aside class="notes">备注</aside>
</section>
  • 代码不超过 14 行
  • 用 span.hl 高亮关键行
  • 前后对比时放两栏
结论页：用一句话把整场演示收住，听众往往只记得住这一句。
