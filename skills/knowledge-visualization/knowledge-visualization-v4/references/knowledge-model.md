# Knowledge Model

The knowledge model is an internal model, not necessarily the final picture.

## Elements

- Entity
- Concept
- Relation
- Process
- State
- Cause
- Constraint
- Hierarchy
- Change
- Evidence
- Perspective

## Selection rule

For each element ask:

> Does this element contribute directly to the intended understanding?

Classify each element as:

1. Primary
2. Secondary
3. Context
4. Omit

The visual should primarily contain Primary and selected Secondary information.
