# Composition

## Primary path

Give the main narrative the strongest visual weight.

Common patterns:

```text
START → CORE → RESULT
```

```text
CAUSE → MECHANISM → EFFECT
```

```text
USER → SYSTEM → DECISION → OUTPUT
```

## Secondary information

Attach it to the relevant part of the primary path. Do not create independent cards unless the information is genuinely independent.

## Density

If crowded:

1. remove irrelevant content
2. group related content
3. simplify labels
4. split visuals

Do not simply shrink everything.
