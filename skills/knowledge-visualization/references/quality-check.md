# Quality Check

## Cognitive

[ ] Primary question is clear.
[ ] Intended understanding can be stated in one sentence.
[ ] One dominant cognitive target.

## Knowledge

[ ] Important entities and relationships are correct.
[ ] No essential mechanism was removed.
[ ] No unsupported precision was invented.
[ ] Concept inventory has been reduced to relationships necessary for the target.

## Narrative

[ ] Obvious starting point.
[ ] Main path leads to the result or intended understanding.
[ ] Secondary information supports the main path.
[ ] Narrative can be stated as a single attention path.

## Visual Structure

[ ] Dominant relationship is explicitly identified.
[ ] The relationships necessary for understanding are represented spatially.
[ ] Control/data/causal/state relationships have distinguishable visual expressions.
[ ] Primary relationships are visually stronger than secondary relationships.
[ ] Secondary information attaches to the primary mechanism instead of becoming competing cards.

## Visual Dominance

[ ] There is exactly one primary visual structure.
[ ] The primary structure owns the strongest spatial continuity.
[ ] Supporting regions do not have comparable visual weight.
[ ] The primary mechanism remains understandable when supporting regions are removed.
[ ] No secondary section accidentally introduces a second independent narrative.

## Visual Budget

[ ] Most visual attention is spent on the primary mechanism.
[ ] Context and reference details are restrained.
[ ] Decoration is minimal.
[ ] The solution does not shrink everything merely to fit more knowledge.

## Visual Reconstruction Test

[ ] Without explanatory prose, the viewer can identify the main actors/elements.
[ ] Without explanatory prose, the viewer can identify who drives/affects whom when applicable.
[ ] Without explanatory prose, the viewer can follow the main flow/state transition/causal chain.
[ ] Important loops, feedback, or rescheduling relationships are visually visible when applicable.
[ ] The visual answers the core question more directly than a list of facts would.

## Dominance Test

[ ] Primary-only test passes.
[ ] Competition test passes.
[ ] One-path attention test passes.

## Visual

[ ] Diagram type matches the narrative and visual structure.
[ ] Visual hierarchy is clear.
[ ] Arrows have semantic meaning.
[ ] Colors have semantic meaning.
[ ] Decoration is subordinate.
[ ] Text supports the visual structure rather than replacing it.
