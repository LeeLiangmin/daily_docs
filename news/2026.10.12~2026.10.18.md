# Rust 一周热点

本周 Rust 的热点集中在两条线上。产业侧，AI 辅助的大规模 Rust 重写再次引发关注，Ubuntu 也完成了 Rust 版核心工具链的切换。技术侧，Linux 7.3 发布，7.4 合并窗口开启，Rust 驱动开始取代 C 驱动；重要 TLS 库 Rustls 也发布了一次安全更新。

---

## 一、产业动态

### 1. [AI 用 2.4 万美元把 TypeScript 编译器移植到 Rust，作者称速度为官方 Go 版两倍](https://www.theregister.com/devops/2026/10/15/24000-ai-experiment-ports-typescript-compiler-to-rust/5303409)

开发者、YouTuber Theo Browne 借助 AI 智能体把微软的 TypeScript 编译器移植到了 Rust。据他介绍，这个 Rust 版本的速度是微软今年发布的官方 Go 版（v7）的两倍，是上一代 TypeScript（v6）的 12.5 倍。他还表示自己甚至没有审阅过这些代码。移植范围不止编译器本身，还包括类型检查器，以及为编辑器提供报错和补全功能的语言服务器。

这次尝试经历了一轮失败。Browne 起初使用 OpenAI 的模型，消耗了按 API 价格计超过 40 万美元的 token，兼容性做到约 84% 后就推进不下去了。Claude Opus 5.5 发布后，他重新尝试，这次约 2.4 万美元的 token 就得到了可用的实现，TypeScript 一致性测试的通过率接近 100%。关键在于翻译路径：模型没有从 JavaScript 直接翻译，而是以微软的 Go 版实现为蓝本移植，因此也把原版的几个 bug 一起带了过来。

需要注意的是，这些性能数据尚未经过独立验证。这件事也处在一个更大的趋势里：微软此前用约 12 万美元的 AI 开销把 Copilot 运行时重写为 Rust，谷歌也在用 AI 智能体把 RE2、libgav1 以及 Fuchsia 的 Zircon 内核部分代码等 C/C++ 项目迁移到 Rust。

### 2. [Ubuntu 26.10 正式发布，Rust 版 Coreutils 迁移全面完成](https://www.phoronix.com/news/Ubuntu-26.10-Released)

Canonical 发布 Ubuntu 26.10 "Stonking Stingray"。新版本搭载接近最终版的 Linux 7.3 内核和 GNOME 51 桌面，基于 Rust 的 Coreutils 替换工作也已全部完成。这意味着 `ls`、`cp`、`mv` 等最常用的命令行工具，在主流发行版上第一次默认全部由 Rust 实现。

这只是 Ubuntu "Rust 化"路线的一步。Canonical 已重申，计划在 Ubuntu 27.04 中默认采用 ntpd-rs 作为时间同步服务，下一步还可能用 Sequoia PGP 取代现有的 OpenPGP 实现。

## 二、项目与技术进展

### 3. [Linux 7.3 发布，7.4 合并窗口开启：Rust 版 Binder 将取代 C 版](https://www.phoronix.com/news/Linux-7.4-Features-Preview)

Linux 7.3 内核按期发布，随后 Linux 7.4 合并窗口开启。7.4 中与 Rust 相关的最大看点是，谷歌的 C 语言版 Binder 驱动将被移除，由 Rust 版接替。

Binder 是 Android 进程间通信的核心组件。它的 Rust 重写版是最早一批"真正"的 Rust 驱动之一，已在 Linux 6.18 进入主线。开发者认为，Rust 版已经证明自己更容易维护和扩展，性能也与原版相当甚至更快。谷歌方面的说法是，C 版驱动历经 15 年多，已经复杂到难以维护，添加新功能时很容易引入漏洞。一个核心 C 驱动被 Rust 版直接替换，这在主线内核中颇具标志性。

GPU 驱动方面，面向 7.4 的 DRM Rust 改动已提交至 DRM-Next，主要是英伟达 Nova 驱动的更新。Nova 将新增供子驱动使用的 NovaCoreApi，以及向用户空间报告 GPU 架构、芯片 ID 和显存信息的 ioctl，还加入了显存伙伴分配、TLB 刷新、MMU v2/v3 页表等内存管理功能。（[详情](https://www.phoronix.com/news/NVIDIA-Nova-Linux-7.4-Changes)）

### 4. [Rustls 0.23.46 发布，一次修复四项安全问题](https://www.phoronix.com/news/Rustls-0.23.46-Released)

用 Rust 编写、以内存安全为卖点的 TLS 库 Rustls 发布 0.23.46，修复了四个安全问题。前两个涉及资源和密钥：一是内置但默认关闭的 Brotli 证书解压，可能在认证前就分配由攻击者控制大小的内存，最高可达 1GB；二是会话的调试格式化输出会暴露 TLS 主密钥和会话恢复用的 PSK，这些密钥可能因此被写进日志文件。

另外两个出在握手流程上：未经认证的 ServerHello 可以污染按主机名缓存的密钥交换提示，导致之后的 ClientHello 只携带传统的 X25519 密钥份额；客户端在握手完成前缓冲的应用数据，即使服务器拒绝了加密客户端问候（ECH），仍会被发送出去。

值得一提的是漏洞的来源：本版修复的 bug 中有 13 个由 OpenAI 发现并报告，其中包括两个安全问题。这说明即便是内存安全语言写的库，逻辑层面的协议安全问题依然存在，而 AI 正在成为发现这类问题的重要力量。

### 5. [Servo 浏览器引擎支持 CSS Grid，实验性 Threadboost 让跑分提升 50%](https://www.phoronix.com/news/Servo-0.6-Changes)

Servo 迟到的八月进展报告近日发布，梳理了这个基于 Rust 的开源浏览器引擎的最新进展，此前 Servo 0.6 及其演示浏览器 Servoshell 刚刚发布。最重要的新功能是 CSS Grid：支持落地后，更多网站可以在 Servo 上正确渲染了。

性能方面，实验性的 Threadboost 功能让 Speedometer 基准测试成绩提升了 50%。Threadboost 针对的是大小核架构：在 big.LITTLE 这类异构 CPU 上，系统调度器未必能判断哪些线程最关键，这个模块用于设定线程亲和性、优先级和核心频率提升等策略。此外，Servo 还引入了 SpiderMonkey 153 以修复安全和崩溃问题，并新增了一个可选启用的磁盘 HTTP 缓存，不过目前还无法清空。

### 6. [Rust 基础设施团队：crates.io 上线 WAF 与 DDoS 防护，RISC-V musl 升至二级平台](https://blog.rust-lang.org/inside-rust/2026/10/12/infrastructure-team-q3-recap-and-q4-plan/)

Rust 基础设施团队发布季度报告，重点是供应链安全。团队与 crates.io、docs.rs 团队合作，为两个站点部署了 Fastly 新一代 Web 应用防火墙（WAF）并启用 DDoS 防护。这些措施帮助缓解了本季度针对 crates.io 的 DDoS 攻击，也减轻了 docs.rs 服务器的负载。同时，团队为 `rust-lang/rust` 仓库配置了 Renovate，自动提交修复安全问题、更新依赖锁文件的 PR，并把 7 个官方 crate（包括 libc）改为可信发布（trusted publishing）。

平台支持方面，`riscv64gc-unknown-linux-musl` 被提升为带宿主工具的二级平台，RISC-V musl 用户不再需要自己编译 rustc 和 cargo。团队还新增了一台 ARM 服务器运行 rustc-perf，供编译器团队衡量针对 ARM 的优化效果。下季度的重点之一是部署方式：目前基础设施仍从成员的个人笔记本电脑部署，团队计划改为在访问受控的安全环境中统一部署。

## 三、社区与治理

### 7. [Rust 基金会董事会换届：两名新项目董事当选](https://rustfoundation.org/media/rust-foundation-board-updates-october-2026/)

Rust 基金会宣布，Jana Dönszelmann 和 Nia Deckers 当选新一届项目董事，Jess Wass 出任 Meta 在董事会的新代表。卸任的项目董事 Carol Nichols 和 Ryan Levick 获公开致谢。两位新董事都来自一线技术岗位。Jana 是 Rust 编译器团队成员，主持每周两次的编译器答疑时间，此前曾在代尔夫特理工大学教授 Rust。Nia 目前领导标准库团队，是推动自定义内存分配器进入语言的主要力量之一。

### 8. [EuroRust 2026 在巴塞罗那举行](https://rustfoundation.org/event/eurorust-2026/)

欧洲规模最大的 Rust 会议之一 EuroRust 本周在巴塞罗那举行，同时提供线上参与。大会包括两天正会，另有两天工作坊、黑客松和城市游览等活动，议题从 Rust 编程模式、系统编程、命令行工具，到服务端、WebAssembly 和嵌入式，覆盖面很广。
